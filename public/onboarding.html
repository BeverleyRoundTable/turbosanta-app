Deploy the TurboSanta API

Must be completed first — everything else depends on this

The Apps Script API is the invisible brain connecting your Sheet to the live map, Santa's speed calculations, and all your public tools.

  1. In your Sheet, go to Extensions → Apps Script.

  2. Click Deploy → New deployment.

  3. Choose Web app as the deployment type.

  4. Set Execute as: Me and Who has access: Anyone.

  5. Click Deploy, authorise permissions, and copy the Web App URL.

  6. Paste the URL into the Settings tab — find the row where Column A = api_url and set Column B to your URL.

⚠️
Always update deployments after edits

If you ever edit Apps Script, go to Deploy → Manage deployments → Update. Old deployments serve stale code and will cause silent bugs.

Firebase Setup

Live sleigh location, analytics, and subscriber notifications

Understanding Your Two Firebase Keys

TurboSanta uses two distinct keys in the Tracker sheet. These are not interchangeable:

KeyWhat it doesWhere it lives
secret GPS write key. Embedded in the Firebase write path. Permits writing the live location only. Safe to rotate if the sleigh phone is lost. Beacon config / GPS Logger URL
firebase_db_secret Admin key (Legacy Database Secret). Used server-side by Apps Script for reading subscribers, analytics, and history. Never exposed to the public. Apps Script only
⚠️
Common Mistake

Setting both keys to the same value appears to work but breaks your Firebase security rules. The secret is used as a path segment in Firebase rules; firebase_db_secret is used for authentication. They must be different.

Create Your Firebase Project

  1. Visit https://firebase.google.com and create a new project.

  2. Go to Build → Realtime Database and create a database — choose Region: Europe.

  3. Copy your Database URL and paste it into Tracker → firebase_url.

  4. Go to Project Settings → Service Accounts → Database Secrets to find your firebase_db_secret.

Create Placeholder Nodes

Firebase automatically deletes empty nodes. The following placeholders must exist before any data is sent — create each with the value placeholder: true:

  • location
  • location/current
  • analytics
  • analytics/views

Security Rules

Open Realtime Database → Rules and paste the following. Replace YOUR_SECRET with your actual secret value.

JSON Firebase Security Rules 
{
  "rules": {
    ".read": false,
    ".write": false,
    "location": {
      "current": {
        "$secret": {
          ".write": "$secret === 'YOUR_SECRET'"
        }
      },
      "history": {
        ".read": false,
        ".write": "auth !== null",
        ".indexOn": ["ts"]
      }
    },
    "analytics": {
      ".read": false,
      ".write": false,
      "views": { ".indexOn": ["ts"] }
    },
    "subscribers": {
      ".read": false,
      ".write": false
    }
  }
}

Automatic Data Cleanup

TurboSanta prunes old Firebase data automatically in the background to keep things lean:

Data TypeRetention Rule
GPS HistoryEntries older than 90 minutes are deleted every time the notification checker runs.

Sleigh GPS Transmitters

Choose your transmission setup depending on who is driving

The sleigh phone needs to push GPS coordinates to Firebase every few seconds. TurboSanta gives you two main options. Both write the same {lat, lng, ts} payload to Firebase, so the tracker, God Mode, notifications, and history all work identically regardless of which one you use.

Option A — Solo Driver Setup
🧭 Sat-Nav & Beacon (Merged)
One phone does it all. The driver opens the Tracker in Driver Mode. It provides a turn-by-turn routing arrow AND securely transmits the sleigh's location in the background simultaneously. Authenticates via God Mode password.
✅ Visual Routing · ✅ Offline Buffering · ✅ Keeps screen awake
Option B — Bulletproof Setup
📡 Dedicated Beacon Phone
A cheap spare phone runs the standalone TurboSanta Beacon page. Plug it into a power bank, stash it in the glovebox, and forget it. The driver uses a *second* phone for navigation.
✅ Driver can use their personal phone freely · ✅ Offline Buffering
💡
Which one should I use?

If the driver needs to use their phone to check texts or change music, use Option B. Mobile browsers aggressively pause GPS tracking when a tab is pushed to the background. Using a dedicated glovebox phone ensures the signal never drops. If the driver is strictly navigating and won't touch other apps, Option A is perfect.

Option A: Solo Driver (Sat-Nav & Beacon)

  1. Open the Tracker link and add &driver=1 to the end (or click Sat Nav from the Landing Page).

  2. Tap the red 🧭 START SAT-NAV & BEACON button.

  3. Enter the Beacon password when prompted to authorize the GPS transmitter.

  4. A status pill will appear at the top. 📡 LIVE (Green) means it's transmitting successfully. 📦 BUFFERING (Amber) means you've hit a dead zone and it is saving fixes locally to replay later.

Option B: Dedicated Beacon Setup

  1. Open the Beacon URL from your Dab Santa Landing Page, or navigate to: beacon?api=YOUR_API_URL

  2. Enter the Beacon password.

  3. Tap ▶ START — the pulsing green ring confirms GPS is transmitting.

  4. Mount the phone, plug it into a power bank, and leave the screen visible. (iPhone users: Set Auto-Lock to Never in iOS Settings).

ℹ️
Legacy Option: GPS Logger App

If you prefer using a native third-party Android app instead of a web browser, you can still install GPS Logger from the Play Store. Paste the GPS Logger URL from your Tracker sheet (cell B7) into the app's custom URL field. Note: Native apps do not have the offline buffering feature.

Advanced Settings

Key settings rows not covered by the Wizards — all live in the Settings tab
ℹ️
How the Settings Tab Works

The Settings tab has four separate data areas, not just one. Column A/B is the key-value store. Column Q, S, and U hold additional list data used by specific features — do not delete or move these columns.

PA Presets (Column S)

Column S of the Settings sheet (from S2 downwards) holds pre-written PA announcement messages. The API reads this column on every request and returns them as a presets array, which God Mode loads into a dropdown so your Lead Elf can fire canned announcements quickly without typing on a cold night.

  • Each cell in S2:S is one preset message — one per row.
  • Blank cells between entries are ignored.
  • These are separate from the public PA system's live message — presets are pre-loaded options; live_announcement is what's actively broadcasting.

Donations Route Dropdown (Column Q)

Column Q of the Settings sheet (from Q2 downwards) holds the list of route names that appear in the Donations Wizard dropdown when logging cash/card totals. Keep this in sync with your Routes tab.

Volunteer Roles (Column U)

Column U of the Settings sheet (from U2 downwards) holds the list of volunteer roles that appear in the Crew Hub sign-up form and the Volunteer Certificate Generator. Both tools read this list dynamically from the API — add, remove, or reorder roles in the sheet and they update automatically.

  • One role per row — e.g. Driver, Collections, Lead Elf, Santa, Tech/GPS, Safety Walkers.
  • If Column U is empty, both tools fall back to a sensible default list.

Live Announcement (PA System)

The live_announcement key in Settings is the public PA system. When set, its value overrides the normal status box on every viewer's tracker with a pulsing gold announcement banner.

Messages to Santa

The public 💬 Msg Santa button lets viewers send a short message (max 50 characters) to the sleigh. Messages go into a moderation queue in God Mode — the Lead Elf can approve or reject each one. Approved messages appear as a pulsing purple banner on the public tracker for 20 seconds, then disappear automatically.

  • Enable the feature by setting enable_user_messages to TRUE in Settings.
  • The button only appears when GPS is live and a route is active — hidden in kiosk mode.
  • God Mode polls for pending messages every 10 seconds and shows the originating route name next to each one.

Crew Alert

The crew_alert key in Settings drives internal messaging from the Lead Elf to all volunteers on the Crew Hub — completely separate from the public PA system and never visible on the public tracker.

Elf Cam URL

The elf_cam_url key powers the Elf Cam polaroid feature. When the Elf Cam captures a new photo, it writes the Google Drive URL here. The tracker polls for changes and displays any new image as a floating Polaroid on the public map.

Sleigh Cam (Twitch Stream)

The enable_twitch toggle controls visibility of the 📺 Sleigh Cam button on the public tracker. When enabled and twitch_channel is set to your Twitch channel name, viewers see a Cam button in the control bar. Tapping it opens a Twitch player overlay on the map. The stream starts muted due to browser autoplay policy — viewers tap unmute within the player for audio.

  • Enable by setting enable_twitch to TRUE and twitch_channel to your channel name (e.g. beverleyroundtable) in Settings.
  • Set enable_twitch to FALSE or blank to hide the button — useful when you're not streaming.
  • Hidden automatically in kiosk and driver modes.
  • The Twitch embed dynamically reads the hosting domain, so it works on any table's Cloudflare Pages URL or custom domain without configuration.

GET_PEAK_VIEWERS Formula

TurboSanta includes a custom Google Sheets formula to calculate peak simultaneous viewers within any time window:

Google Sheets Custom Formula 
=GET_PEAK_VIEWERS(E2:E, 15)

🎵 Dynamic Sleigh Music

The public tracker includes a built-in music player that acts as a subliminal audio cue for families. When enabled, a 🔇 Music button appears on the tracker. The volume is intelligently tied to Santa's ETA:

  • Ambient (No Pin / > 15 mins): Plays quietly at 15% volume in the background.
  • Approaching (< 15 mins): Volume gently ramps up to 25%.
  • Getting Close (< 8 mins): Volume increases to 50%.
  • Imminent (< 3 mins): Volume pushes to 80% to build excitement.
  • Arrival: When Santa hits the user's location, the volume spikes to 100% for 3 seconds alongside the visual fireworks!

Subscriber Email Notifications

Up to two automated emails per subscriber per sleigh night

Email 1 — "Santa's Nearly Here"

Triggered when either condition is met and GPS is fresh (under 90 seconds old):

  • Santa's estimated arrival is under 5 minutes based on calculated speed, or
  • Santa is within 250 metres of the subscriber's pin.

Email 2 — "Santa's Just Been Past"

Triggered after Email 1 when either condition is met:

  • Santa has moved more than 150m further away from the subscriber's closest recorded distance AND at least 1 minute has passed since Email 1, or
  • 20 minutes have passed since Email 1 (timeout fallback).
⚠️
Month Guard — Currently Disabled

The notification code contains a month guard that is currently force-overridden to allowEmails = true for testing. Before going live, switch it to the production version: const allowEmails = (month === 11 || month === 0);

Route Planner

Design custom routes, auto-detect streets, and export dense GPX files
ℹ️
Alternative: gpx.studio

If you prefer an external tool, gpx.studio can also create road-snapped routes. However, you will need to manually compile street names and the exported GPX files may require densification before use with the Sat-Nav or Animator.

The Route Planner is a standalone pre-season tool. It replaces generic tools like Google My Maps, solving the two biggest headaches of Santa logistics: generating dense GPX files and compiling street lists.

📍 Building & Snapping

  • Build Route Mode: Click the map to drop waypoints. The tool automatically snaps the path to valid roads (using Walking, Driving, or Cycling profiles).
  • Adjusting: Drag waypoints to tweak the route, or right-click a marker to delete it.
  • Existing Routes: If opened via the Landing Page (with the ?api= parameter), the planner overlays your already-saved routes in faint blue so you avoid overlapping territories.

🏘️ Automatic Street Detection

Once your route is drawn (or a GPX is uploaded), the planner samples the geometry and reverse-geocodes it via OpenStreetMap to detect every street name along the path.

  • Wait for the Detecting streets... progress bar to finish scanning.
  • Click 📋 Copy for Sheet to copy the comma-separated list.
  • Paste this directly into Column H (Streets) of your Routes tab. This instantly populates the public Address Lookup tool!

⚙️ Densification & Export

Standard routing tools create "sparse" GPX files (only dropping points at corners). TurboSanta's Sat-Nav, GPX Animator, and GPS bounding boxes rely on "dense" GPX files to work flawlessly.

💡
Recommended Settings

Leave Density at 10m. This ensures the Sat-Nav arrow tracks smoothly between junctions and the Animator sprite doesn't jump through buildings.

  • Speed Slider: Adjust Santa's crawling speed (e.g., 3 mph) to get an accurate Est. Time for the night.
  • Click ⬇ Export Dense GPX to download the file. Upload this to Google Drive and paste the link into the Routes tab.

Viral Protection & Scaling

Optional — for power users expecting large audiences

Google Apps Script has a hard limit of 30 simultaneous connections. A free Cloudflare Worker eliminates this risk entirely — cost: £0.00, capacity: 100,000+ simultaneous viewers.

Step-by-Step Cloudflare Setup

  1. Visit https://dash.cloudflare.com and create a free account.

  2. Go to Workers & Pages → Create Worker. Name it, click Deploy, then click Edit Code.

  3. Delete all default code and paste the worker script below.

  4. Critical: Replace the GAS_URL on line 3 with your actual Google Apps Script Web App URL.

  5. Click Deploy. Update your api_url in Settings to the new Worker URL.

JavaScript Cloudflare Worker — paste into editor 
export default {
  async fetch(request, env, ctx) {
    const GAS_URL = "https://script.google.com/macros/s/YOUR_SCRIPT_ID/exec";
    const url = new URL(request.url);
    const targetUrl = GAS_URL + url.search;
    const cache = caches.default;
    const cacheKey = new Request(targetUrl, request);
    let response = await cache.match(cacheKey);
    if (!response) {
      response = await fetch(targetUrl);
      response = new Response(response.body, response);
      response.headers.set("Cache-Control", "s-maxage=5");
      response.headers.set("Access-Control-Allow-Origin", "*");
      ctx.waitUntil(cache.put(cacheKey, response.clone()));
    } else {
      response = new Response(response.body, response);
      response.headers.set("Access-Control-Allow-Origin", "*");
    }
    return response;
  }
};

Sat-Nav Driver Mode

Precise GPX-following navigation for the towing vehicle

TurboSanta's Sat-Nav strictly follows your loaded GPX routes — unlike Google Maps, which tries to recalculate and skip cul-de-sacs. Depending on your setup from Section 04, you can use the Sat-Nav to simply navigate, or to navigate and transmit the sleigh's location simultaneously.

Activating Sat-Nav Mode on the Night

  1. Open your Dab Santa Landing Page and click Sat Nav. (Alternatively, open your standard tracker link and add &driver=1 to the end of the URL.)

  2. A large red 🧭 START SAT-NAV & BEACON button will appear. Tap it.

  3. Authorize: Enter the Beacon password when prompted. This securely fetches the Firebase API credentials needed to transmit your location.

  4. If your browser requests Location Permissions, tap Allow.

  5. The screen zooms to street level, the blue arrow appears, and public UI buttons (Donate, Notify) vanish to prevent distractions.

  6. Watch the Pill: Look at the status pill at the top of the screen. 📡 LIVE (Green) means you are actively transmitting. 📦 BUFFERING (Amber) means you've hit a mobile dead zone and fixes are being saved offline to push later.

⚠️
Keep the App Open

If you are using the Sat-Nav as your primary GPS transmitter, you must keep the browser tab open and visible on the screen. If the driver puts the phone to sleep or switches apps to check a text message, the browser will pause the GPS tracking.

Community Memory Book

Crowdsourced polaroid gallery with moderation and time-machine archives

The Memory Book is a dedicated public page where your community can upload and view photos from the sleigh routes. It builds a permanent, crowdsourced visual history of your Round Table's impact without you having to manually chase families for photos.

🛡️ The Moderation Queue

To ensure absolute brand safety, photos do not appear publicly the moment they are uploaded. Instead, they follow a strict approval flow:

  • Smart Uploads: When a user selects a photo, the app automatically compresses it inside their browser (down to a max of 1200px). This saves mobile data for the user and prevents your database from filling up with massive 10MB files.
  • The Queue: The compressed photo is sent to God Mode / your backend Sheet with an "Awaiting Approval" status.
  • Going Live: Once the Lead Elf reviews and approves the photo, it immediately joins the public gallery.

✨ Dynamic Polaroids & Time Machine

The gallery isn't just a static grid. Each approved photo is rendered as a stylized, slightly tilted Polaroid. To keep the gallery feeling fresh, the system applies a randomly selected festive caption (e.g., "Making memories!", "Sleighing it!", "Sparkle and shine!") from a pool of 50+ unique phrases.

If your database contains approved photos from previous years, the ⏳ Archive Time Machine dropdown automatically appears at the top of the page, allowing the community to browse past seasons.

💡
Promoting the Memory Book

The best time to push the Memory Book is the morning after a route, or at the very end of the season. Link to it from your Public Thank You Page and social media posts to encourage families to upload their favourite snaps.

Magic Mailbox & Santa Studio

Receive voice messages from children and reply with magical audio emails

The Magic Mailbox is an interactive web app where children can hit record and send a real voice message directly to "Lapland" (your backend). To maintain the magic, volunteers act as elves and use the Santa Studio dashboard to listen and reply.

🎙️ The Public Mailbox

  • No App Required: Families open the link, grant microphone access, and record their wishlist.
  • Secure Storage: Audio files are securely uploaded directly to a private folder in your Google Drive. They are never made public.
  • Parental Consent: GDPR-compliant tickboxes ensure parents consent to the recording and provide their email address for the reply.

🎧 Santa Studio (Volunteer Dashboard)

Santa Studio is a secure portal (protected by the God Mode password) where your "Elves" process the incoming messages.

ℹ️
The Concurrency Engine

If multiple elves are working at the same time, the system prevents them from answering the same child. When an elf clicks on a message, it is instantly "Claimed" across all devices. Claims expire after 10 minutes to prevent locked messages if an elf closes their browser.

  • Listen & Record: Elves play the child's message, then hold the record button to reply in their best Santa (or Elf) voice.
  • Automated Delivery: Once submitted, the system generates a branded HTML email, attaches a secure link to the audio reply, and emails it directly to the parents.
  • Flagging System: If a message is inappropriate, blank, or concerning, elves can "Flag" it to hide it from the main queue and notify the Lead Elf.
